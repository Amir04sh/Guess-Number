# Guess-Number
---
🎯 Number Guessing Game

A fun and interactive number guessing game built with HTML, CSS, and JavaScript.

Try to guess the secret number between 1 and 100 using as few attempts as possible!
---
>✨ Features

🎯 Random number between 1 and 100

👆 Hints to guess a higher number

👇 Hints to guess a lower number

🔢 Tracks the number of attempts

🏆 Saves your best score using Local Storage

🔄 Start a new game anytime

📱 Responsive design

>🎮 How to Play

1. Enter a number between 1 and 100.


2. Click the Guess button.


3. Follow the hints:

👆 Go Higher — Try a higher number.

👇 Go Lower — Try a lower number.

4. Keep guessing until you find the correct number.

5. Try to win in as few attempts as possible!


6. Click New Game to start a new round.
---

🏆 Best Score

Your best score is saved in your browser using Local Storage.

The fewer attempts you need to guess the correct number, the better your score!
